| 检查 | 结果与证据 |
| --- | --- |
| 原生构建 | SwiftUI 管理器、自有启动器、内置引擎均编译成功，应用和内置浏览器使用独立标识与本地图标 |
| 私有目录与配置 | CoreTests 通过：0700/0600、独占锁、配置往返、损坏配置保留、无效版本/重复 UUID/重复 seed 拒绝、符号链接拒绝 |
| 启动参数 | Google 默认页及空值回退、真实系统/CPU/引擎版本、参数边界、HTTP 代理与回环豁免通过；产品默认参数无调试端口 |
| 真实并发浏览器 | 两个有界面浏览器同时运行，独立资料目录，语言 en-US / ja-JP，时区 America/New_York / Asia/Tokyo，定位权限 denied |
| 指纹 | 相同本机测试站点上的 Canvas 摘要不同且各自稳定；示例 SHA256 前缀 5d80e5a7834c7412 / 0709f83a0a1f2b8d |
| 同源资料隔离 | A 的 Cookie/localStorage 不出现在 B；分别写入后仍互不影响 |
| 正常退出与重启 | 退出 A 后 B 保持可用；重启 A 后持久 Cookie、localStorage 和指纹保持一致；结束后两个测试浏览器均退出 |
| 独立 HTTP 代理 | 两个本机 HTTP 代理分别向相同测试域名返回不同标记，两浏览器各自读到对应标记；未访问真实外部测试站点 |
| 独立交付目录 | 使用 FENJING_TEST_ENGINE 指向 `$DELIVERY/FenJing.app` 内部引擎重复通过代理/并发/隔离/退出回归 |
| GUI 表单与搜索 | 原生界面实际操作通过新建、编辑、复制、搜索筛选、Google 起始页保存、默认 HTTP/共享主机端口表单；无效 seed 和端口阻止保存 |
| GUI 多开与 Dashboard | 批量启动后显示 2 个运行；卡片「正常退出」A 后显示 1 个运行；「正常退出全部」后显示 0 个运行，资料保留；所选退出入口按运行状态启用/禁用 |
| 管理器重开 | 通过应用菜单退出管理器，再打开时仍识别正在运行的浏览器，显示 1 个运行 |
| 默认网站与品牌 | 内置浏览器实际打开 https://www.google.com；系统显示「分境浏览器」，应用菜单为 FenJing Browser；无原宿主启动器 |
| 界面 | 原生磨砂背景、蓝绿色玻璃侧栏、统一深色透明标题栏、圆角工作区和卡片已经截图检查 |
| 打包 | 独立 App 约 368 MiB；DMG 174507510 bytes；SHA256SUMS.txt 已生成。verify-bundle 通过内部链接、独立标识、自有图标、许可和 codesign 深度校验 |

交付物位于 `$DELIVERY/`。本机保留两个空登录环境供使用，它们在用户资料目录中，未包含在安装包内。

范围限制：没有在另一台 Mac、macOS 13、Intel 或 Windows 上实测；构建目标是 macOS 13+ arm64。当前为本地临时签名，未做 Developer ID 签名/公证。没有测试真实账号登录、付费代理供应商或 HTTP 代理账号密码；不作匿名、DNS/WebRTC 全面无泄漏或网站账号可接受性的保证。
