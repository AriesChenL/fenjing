## 0.1.1 本地候选版

- 原生玻璃：磨砂移至 NSView 底层，采用 behindWindow/sidebar/active 材质；NSHostingView 和其 layer 均保持非不透明，颜色蒙层降低。已实际启动并检查界面。系统的“减少透明度”处于关闭状态，未修改系统设置。
- Dock 图标：管理器蓝色叠层、浏览器琥珀色地球；图标文件不同、浏览器图标资源名独立，重新完成签名与 bundle 校验。
- 回归：旧配置缺失可选字段仍可解码；默认 HTTP/2 保留；显式选中的 HTTP/HTTPS 环境才追加兼容参数，系统路由和 SOCKS5 不受影响；核心回归通过。
- Google：命令行经该代理的 Google/IP.SB HTTPS 和完整静态资源下载正常；临时浏览器中复现 www.gstatic.com 脚本/样式和 fonts.gstatic.com 字体等待。系统路由下两个干净环境的 Google 完整加载通过。普通 Chrome 的独立临时资料通过同一 HTTP 代理也复现了持续 loading，因此不能归结为分境独有缺陷。
- 兼容模式：曾在两个干净环境完成四次 Google 完整加载；后续仍捕捉到字体等待。该模式属于可选缓解措施，不是已证明的通用根治方案。现有用户环境启用该模式后已实际显示完整 Google 页面和 Reload 按钮。
- 测试不会记录页面正文、Cookie、代理凭据或出口 IP。网络日志仅来自无账号的临时环境，保留在忽略的本地 build 目录，不发布。用户浏览器资料没有清理。
- 本地验证完成后，发布由版本标签触发 GitHub Actions，云端构建/发布结果以对应 Actions run 与 Release 为准。
